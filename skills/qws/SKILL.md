# QWS

这是公开包的统一入口。当前公开包包含两个 Skill：

- `qws-interview`：通过连续、非诱导式采访，把用户尚未说清的经历、想法和判断整理成显性知识；
- `qws-zoom-out`：用户明确要求升维或从全局看时，判断当前卡在哪一类打转，并在同一条回复里给出改法。

执行时：

1. 根据用户请求选择对应的 Skill：想接受采访、把经历或想法说清、整理已有采访记录时选 `qws-interview`；明确要求升维、从全局看、检查是否只在局部解决时选 `qws-zoom-out`。请求不明确时，只问一个问题让用户选择。
2. 读取同一安装中所选 Skill 的 `SKILL.md` 全文及它要求的必要资源，按该 Skill 的入口、流程、权限和交付规则继续；本入口不复制、改写或缩减其中的规则。
3. 所选 Skill 未安装或不可读时，明确报告缺少依赖，并请用户重新安装完整公开包；不要凭记忆模拟。

当前公开包没有发布其他 Skill。对两个 Skill 都不负责的任务，不得声称可以调用未安装的内部 Skill。
